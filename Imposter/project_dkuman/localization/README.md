# Localization

**Default:** `en` (English)

**Supported (12):** en, tr, ru, es, pt, de, fr, it, el, ro, nl, pl

## Resolution order
1. Manual language override (Settings → Language), if set
2. Device language / region if in supported list
3. Fallback → `en`

## Placeholders
- `{n}` — number
- `{name}` — player name
- `{id}` — user id
- `{hint}` — imposter hint
- `{rec}` — recommended imposters

## Files
Flat JSON key → string maps. Same keys in every locale.
