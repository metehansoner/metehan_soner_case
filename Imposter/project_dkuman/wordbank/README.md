Kaynak: `Imposter/Resources/WordBank/words.json`

- Her giriş: `word` + `hint` (kısa impostor ipucu)
- Yerelleştirme: **en** + **tr** (diğer diller `en`’e düşer)
- Runtime: `WordBank.randomWord` / `decoyWord` — aktif uygulama diline göre seçer
